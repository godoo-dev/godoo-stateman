    Create src/godoo_stateman/dsl/context.py implementing the DSL proxy objects and the
    exec() namespace factory. All classes sync — no async. No imports from godoo.client.

    Internal state class `_Collector` — a plain class (not frozen dataclass) that accumulates:
    - `resources: list[ResourceNode]` — appended by ResourceProxy calls
    - `data_sources: list[DataSourceNode]` — appended by DataProxy calls
    - `config_parameters: list[dict[str, str]]` — appended by ConfigParameterProxy writes

    `ResourceProxy` — returned as `resource` in the exec namespace:
    - `__getattr__(self, model_name: str)` returns a callable `(slug: str, **fields: Any) -> _ResourceContextManager`
    - The returned callable, when called as `resource.res_partner("slug", name="Acme")`, appends a ResourceNode to the collector and returns a `_ResourceContextManager` wrapping it
    - `_ResourceContextManager` implements `__enter__` (returns the ResourceNode with mutable fields dict for attribute assignment) and `__exit__` (no-op)
    - Inside `with resource.res_partner("slug") as r:` — `r.name = "Acme"` must work; implement via a thin mutable builder that writes to the node's fields dict in __setattr__

    Design note: `@dataclass(frozen=True)` on ResourceNode means its fields dict can be mutated (dict contents are not frozen), but the node reference cannot be replaced. Use a `_ResourceBuilder` (NOT frozen) that holds the mutable fields dict and exposes `__setattr__` for field assignment inside with blocks. After the with block exits or when the resource is first registered, produce the final ResourceNode.

    `DataProxy` — returned as `data` in the exec namespace:
    - `__getattr__(self, model_name: str)` returns a callable `(**selector: Any) -> DataSourceNode`
    - The node_key is computed deterministically: `f"data.{model_name}[{','.join(f'{k}={v!r}' for k, v in sorted(selector.items()))}]"`
    - Appends the DataSourceNode to collector.data_sources and returns it

    `OdooModuleProxy` — returned as `mail` in the exec namespace:
    - `config` property returns a `ConfigParameterProxy` scoped to no specific module prefix (the key is used as-is)
    - `ConfigParameterProxy.__setitem__(key, value)` appends `{"key": key, "value": value}` to collector.config_parameters

    `def children(child_model: str, inverse_field: str, children_list: list[Any]) -> ChildrenWrapper` — plain function, not a proxy method; returned as `children` in the exec namespace.

    `def build_dsl_namespace(collector: _Collector) -> dict[str, Any]`:
    - Returns dict with keys: `"resource"`, `"data"`, `"children"`, `"resolve"`, `"mail"`
    - `"resolve"` is imported from `godoo_stateman.dsl.types.deferred`

    Imports: `from __future__ import annotations`, `from typing import Any`, imports of ResourceNode, DataSourceNode, ChildrenWrapper from `godoo_stateman.dsl.types.nodes`, Deferred and resolve from `godoo_stateman.dsl.types.deferred`.

    `_SAFE_BUILTINS: dict[str, object]` — module-level constant. Include exactly: True, False, None, int, str, float, bool, list, dict, tuple, set, len, range, enumerate, sorted, reversed, zip, map, filter, isinstance, hasattr, getattr, min, max, sum, abs, round, repr, format, Exception, ValueError, TypeError, AttributeError.     `def _flatten(resources: list[ResourceNode]) -> list[ResourceNode]` — private helper implementing D-09/PATTERNS.md Pattern 5:
    - Iterates over each parent resource
    - For each field value that is a ChildrenWrapper, extracts children, prefixes their slugs with `f"{parent.slug}.{child.slug}"`, sets the inverse_field on each child's fields dict pointing to a reference to the parent ResourceNode, appends child ResourceNodes (with parent_slug=parent.slug set) to output
    - Replaces ChildrenWrapper field value in parent with the list of prefixed child slugs (strings)
    - Non-ChildrenWrapper fields pass through unchanged
    - The returned list contains ALL nodes (parents + children) in depth-first order

    `def eval_config(path: Path) -> DesiredState` — public API:
    - Reads config file with `path.read_text()`
    - Compiles with `compile(source, str(path), "exec")` for proper tracebacks (not `exec(path.read_text(), ...)` directly)
    - Creates `_Collector()`, builds `dsl_ns = build_dsl_namespace(collector)`
    - Sets up `exec_globals = {"__builtins__": _SAFE_BUILTINS, **dsl_ns}` and `exec_locals: dict[str, object] = {}`
    - Calls `exec(code, exec_globals, exec_locals)`
    - Extracts `module`: check `exec_locals.get("module")` first, then `exec_globals.get("module")` (Pitfall 2: top-level assignments in the config go to exec_locals when both dicts are passed)
    - If `module` is not a non-empty str, raises `MissingModuleError(f"Config file {path} must declare: module = \"<name>\"")`
    - Calls `_flatten(collector.resources)`
    - Returns `DesiredState(module=module, resources=tuple(flat_resources), data_sources=tuple(collector.data_sources), config_parameters=tuple(collector.config_parameters))`
    - Imports: `from __future__ import annotations`, `from pathlib import Path`, `import dataclasses`, `from typing import Any`, plus internal imports

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config file → exec() | Untrusted-ish Python source evaluated with restricted builtins; trust model is operator-authored, version-controlled configs |
| exec_globals __builtins__ → Python internals | The _SAFE_BUILTINS dict is the security boundary — only allowed names are accessible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Elevation of Privilege | exec() restricted builtins | mitigate | `__import__`, `open`, `eval`, `exec`, `compile` absent from `_SAFE_BUILTINS`; a config attempting `import os` gets `NameError: name 'import' is not defined` [VERIFIED in RESEARCH.md] |
| T-02-04 | Information Disclosure | config file reading open() | mitigate | `open` absent from `_SAFE_BUILTINS` → NameError; config cannot read secrets from filesystem |
| T-02-05 | Denial of Service | infinite loop in config (while True: pass) | accept | DSL is trusted-author context (version-controlled, operator-authored); CPU timeout is an operator concern; no mitigation in Phase 2 per RESEARCH.md Security Domain section |
| T-02-06 | Tampering | ChildrenWrapper not stripped before DesiredState construction | mitigate | _flatten() is called before DesiredState construction in eval_config(); RESEARCH.md Pitfall 5 — assert no ChildrenWrapper in fields after eval (test_inline_children_flatten covers this) |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed in this plan; networkx promoted in Plan 01 (already audited) |
</threat_model>
