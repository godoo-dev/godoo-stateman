<objective>
Normalize stage: canonicalize raw Odoo field values in a DesiredState so two runs against
unchanged state produce bit-identical output. This is the CORE-02 and CORE-08 requirement —
without it the diff stage (Phase 3) would produce false positives on every run.

Purpose: normalize() is called after eval_config() and before build_graph(). It transforms
the raw values captured during DSL eval (which mirror what a DSL author writes) into the
canonical internal representation the diff stage will compare against live Odoo responses.

Output: normalize.py with schema-driven _normalize_value() logic; test_normalize.py with
idempotency, boolean-preservation, m2o extraction, and snapshot=None tests.

    Create src/godoo_stateman/dsl/normalize.py:

    Module docstring: "Normalize stage — canonicalize field values before diff comparison. Converts Odoo False/None patterns to stable internal representations using VersionedSnapshot field metadata."

    `_M2X_TYPES: frozenset[str]` = frozenset({"many2many", "one2many"}) — module-level constant for relation field types.

    `def _normalize_value(value: object, ttype: str) -> object` — private helper:
    - if ttype in _M2X_TYPES: False/None → []; else return value as-is
    - elif ttype == "many2one": False/None → None; (list or tuple) with len==2 → int(value[0]); else return value
    - elif ttype == "boolean": return value AS-IS — do NOT convert False to None. This is the A1 decision per planning_context: `active = False` is a valid desired value meaning "archive"; boolean False must be preserved for the diff stage to correctly detect archive intent. CORE-02's False→None rule explicitly does NOT apply to boolean ttype.
    - else (scalar: char, integer, date, float, selection, etc.): False → None; else return value
    - Imports: `from __future__ import annotations`, `from typing import Any`

    `def normalize(state: DesiredState, snapshot: VersionedSnapshot | None) -> DesiredState` — public API:
    - If snapshot is None: return state unchanged (documented skip path; schema-dependent rules require snapshot)
    - For each resource in state.resources:
      - Get model schema: `model_schema = snapshot.models.get(resource.model)` — if model not in snapshot, resource fields pass through unchanged
      - For each (field_name, value) in resource.fields.items():
        - Get field schema: `field_schema = model_schema.fields.get(field_name) if model_schema else None`
        - If field_schema exists: normalized = `_normalize_value(value, field_schema.ttype)`
        - Else: normalized = value (unknown field — pass through)
      - Build new fields dict with normalized values
      - Use `dataclasses.replace(resource, fields=normalized_fields)` to produce new ResourceNode
    - data_sources and config_parameters are NOT normalized (selectors are author-supplied; config values are string key=value pairs)
    - Return `DesiredState(module=state.module, resources=tuple(normalized_resources), data_sources=state.data_sources, config_parameters=state.config_parameters)`
    - Imports: `from __future__ import annotations`, `import dataclasses`, `from typing import Any`, `from godoo_stateman.dsl.types.desired import DesiredState`, `from godoo_stateman.dsl.types.nodes import ResourceNode`, `from godoo_stateman.schema.snapshot import VersionedSnapshot`
