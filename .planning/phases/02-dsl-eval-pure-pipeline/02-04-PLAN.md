    Create src/godoo_stateman/dsl/graph.py:

    Module docstring: "Dependency DAG construction and cycle detection — REL-01, REL-02, REL-07."

    `def build_graph(state: DesiredState) -> nx.DiGraph` — public API, pure sync:

    Step 1 — Add all nodes:
    - For each resource in state.resources: `G.add_node(resource.slug, node_type="resource")`
    - For each data_source in state.data_sources: `G.add_node(data_source.node_key, node_type="data_source")`

    Step 2 — Add edges from three sources:
    A. Parent→child edges: for each resource where resource.parent_slug is not None, add edge `(resource.parent_slug, resource.slug)` if both nodes exist in G (REL-07)
    B. Deferred.deps edges: for each resource, for each field value that is a `Deferred` instance, for each dep_slug in field_val.deps — if G.has_node(dep_slug), add edge `(dep_slug, resource.slug)` meaning "dep_slug must be resolved before resource.slug"
    C. Direct resource reference edges: for each resource, for each field value that has a `.slug` attribute and G.has_node(field_val.slug), add edge `(field_val.slug, resource.slug)`
    Note: data source node_keys from Deferred.deps are also valid dep targets — `G.has_node(dep_slug)` handles this correctly since data source node_keys are added in Step 1.

    Step 3 — Cycle detection:
    Wrap `nx.find_cycle(G)` in `try/except nx.NetworkXNoCycle` — NOT a None check.
    If cycle found: reconstruct path string `" -> ".join([e[0] for e in cycle_edges] + [cycle_edges[-1][1]])`.
    Raise `CycleError(f"Dependency cycle detected: {cycle_str}")`.
    If no cycle (NetworkXNoCycle raised): continue.

    Return G.

    Imports: `from __future__ import annotations`, `import networkx as nx`, `from godoo_stateman.errors import CycleError`, `from godoo_stateman.dsl.types.desired import DesiredState`, `from godoo_stateman.dsl.types.deferred import Deferred`
