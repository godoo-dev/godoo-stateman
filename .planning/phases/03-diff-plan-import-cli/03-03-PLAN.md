    - `from __future__ import annotations` + `from typing import Any`

    Signature: `def diff(state: DesiredState, live_state: LiveState, snapshot: VersionedSnapshot)
    -> list[PlanStep]:`

    diff() is SYNCHRONOUS and PURE — no client param, no I/O. It reads model schemas from
    `snapshot.models[model]` (sync dict access). The command (Plan 04) builds the snapshot via
    `await registry.build_snapshot(distinct_models)` and passes it in — NEVER call the async
    `registry.get()` from inside diff(). The DataSourceNode IDs (seam result) have already been
    applied to ResourceNodes via `resolve_deferred()` before diff() is called.

    Algorithm:
    1. Build `desired_slugs: set[str]` = {r.slug for r in state.resources}.
    2. For each resource in state.resources:
       a. `effective_prefix = resource.xmlid_module or state.xmlid_prefix` (Pitfall 3). Use it
          when constructing the PlanStep.xmlid value (`f"{effective_prefix}.{resource.slug}"`).
       b. `record = live_state.managed.get(resource.slug)` (keyed by slug = ir.model.data.name)
       c. If record is None → CREATE step (res_id=None, field_diff=())
       d. If record.model != resource.model → REJECT step (res_id=record.res_id, field_diff=())
       e. Else: fetch `live_fields = live_state.live_fields.get(record.res_id, {})`.
          Get model schema: `model_schema = snapshot.models.get(resource.model)`. If model_schema
          is None, treat as no comparable fields (NOOP unless desired declares fields — document
          choice; safest is to compare nothing and emit NOOP, since an unknown model cannot be
          diffed). For each `(fname, desired_val)` in resource.fields.items(): skip if fname not
          in model_schema.fields; let `schema_field = model_schema.fields[fname]`; skip if
          `not schema_field.store or schema_field.readonly` (Pitfall 2). Get `live_val =
          live_fields.get(fname)`. Normalize both: `norm_desired = _normalize_value(desired_val,
          schema_field.ttype)` and `norm_live = _normalize_value(live_val, schema_field.ttype)`.
          If `norm_desired != norm_live` → append FieldDiff(field_name=fname, old_value=norm_live,
          new_value=norm_desired). Emit UPDATE if any diffs, else NOOP.
    3. For slugs in `live_state.managed` but NOT in `desired_slugs`:
       Get model from `live_state.managed[slug].model`. Look up `model_schema =
       snapshot.models.get(model)`. If `model_schema is not None and model_schema.archivable`
       → ARCHIVE step, else → DELETE step. Set `res_id = live_state.managed[slug].res_id`.
    4. Return list of PlanStep in the order: desired-state resources first (preserving iteration
       order), then delete/archive candidates in slug-sorted order.

    Note: deterministic topological ordering for render is handled in render.py (Plan 04),
    not in diff(). diff() produces a flat list; render re-orders by graph topology.
