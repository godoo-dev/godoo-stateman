    Signature: `def diff(state: DesiredState, live_state: LiveState, registry: SchemaRegistry)
    -> list[PlanStep]:`

    The `seam_result` (DataSourceNode IDs) has already been applied to ResourceNodes via
    `resolve_deferred()` before `diff()` is called — diff receives ResourceNodes with Deferred
    fields already resolved. diff() is synchronous and pure.

    Algorithm:
    1. Build `desired_slugs: set[str]` = {r.slug for r in state.resources}.
    2. For each resource in state.resources:
       a. `effective_prefix = resource.xmlid_module or state.xmlid_prefix` (Pitfall 3)
       b. `record = live_state.managed.get(resource.slug)` (keyed by slug = ir.model.data.name)
       c. If record is None → CREATE step (res_id=None, field_diff=())
       d. If record.model != resource.model → REJECT step (res_id=record.res_id, field_diff=())
       e. Else: fetch `live_fields = live_state.live_fields.get(record.res_id, {})`.
          Get model schema: `model_schema = registry.get(resource.model)` (may raise if model
          unknown; let exception propagate — caller handles). For each `(fname, desired_val)`
          in resource.fields.items(): skip if fname not in model_schema.fields, skip if
          `not schema_field.store or schema_field.readonly` (Pitfall 2). Get `live_val =
          live_fields.get(fname)`. Normalize both: `norm_desired = _normalize_value(desired_val,
          schema_field.ttype)` and `norm_live = _normalize_value(live_val, schema_field.ttype)`.
          If `norm_desired != norm_live` → append FieldDiff. Emit UPDATE if any diffs, else NOOP.
    3. For slugs in `live_state.managed` but NOT in `desired_slugs`:
       Get model from `live_state.managed[slug].model`. Fetch `model_schema =
       registry.get(model)`. If `model_schema.archivable` → ARCHIVE step, else → DELETE step.
       Set `res_id = live_state.managed[slug].res_id`.
    4. Return list of PlanStep in the order: desired-state resources first (preserving iteration
       order), then delete/archive candidates in slug-sorted order.

    Note: deterministic topological ordering for render is handled in render.py (Plan 04),
    not in diff(). diff() produces a flat list; render re-orders by graph topology.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Live Odoo field values → diff engine | diff() receives raw Odoo values via LiveState; must normalize before comparison |
| DSL desired values → diff engine | Already normalized by normalize() stage before diff() is called |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | diff() — natural-identity probing forbidden | mitigate | diff() has zero I/O (no client parameter); it is a pure function. Any code path that searches Odoo for look-alike records is impossible by design (D-01 hard constraint). Verified by tests asserting no client mock calls inside diff tests. |
| T-03-07 | Tampering | xmlid-collision → silent Create | mitigate | D-02: when live_state.managed[slug].model != resource.model, action is REJECT. Verified by test_xmlid_collision_produces_reject. |
| T-03-08 | Information Disclosure | Non-stored computed fields in comparison | mitigate | Skip fields where store=False or readonly=True before comparison (Pitfall 2). Only writable, stored fields enter the diff. |
| T-03-01-SC | Tampering | npm/pip/cargo installs | accept | No new package installs in this plan. |
</threat_model>
