    `ACTION_STYLES: dict[PlanAction, str]` mapping for Rich markup:

      ARCHIVE → "magenta", NOOP → "dim"

    `def render_plan(plan_steps: list[PlanStep], graph: nx.DiGraph, console: Console,
    *, verbose: bool = False) -> None`:

    Build `plan_steps_by_slug: dict[str, PlanStep]` from the input list.

    Emit in topological order using `nx.topological_generations(graph)`:
    for each generation, `for slug in sorted(generation)` (D-08 slug tie-breaking):
      step = plan_steps_by_slug.get(slug)
      if step is None: continue (slug may be DataSourceNode not in plan steps)
      if step.action == PlanAction.NOOP and not verbose: continue (D-07)
      symbol = ACTION_SYMBOLS[step.action]
      style = ACTION_STYLES[step.action]
      console.print(f"  [{style}]{symbol}[/{style}] {step.slug}  [{step.model}]")
      if step.action == PlanAction.UPDATE:
          for fd in step.field_diff:
              console.print(f"      {fd.field_name}: {fd.old_value!r} → {fd.new_value!r}")

    After loop: count NoOp steps in plan_steps:
      noop_count = sum(1 for s in plan_steps if s.action == PlanAction.NOOP)
      if noop_count > 0:
          console.print(f"  [dim]{noop_count} resource{'s' if noop_count != 1 else ''} unchanged[/dim]")
