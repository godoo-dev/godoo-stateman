# godoo-stateman

The active delivery is the standalone TypeScript offline foundation described in
the repository [README](https://github.com/godoo-dev/godoo-stateman/blob/main/README.md).
It loads trusted modules and inspects nested identities and content on Node 24+.
Plan/apply/drift and live snapshot workflows remain unavailable in the TS package.

The Python source remains reference material. Product targets and acceptance are
owned by the private godoo-hq README and Stateman roadmap. Offline tests do not
establish live Odoo reconciliation or complete consumer acceptance.
